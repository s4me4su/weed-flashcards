Weed ID Trainer 1.0.0 - 45 swipe flashcards made from the revised weed booklet.
Each card is a booklet page with its name band painted white: name, scientific
name and plant family hidden. Flip it for the page exactly as printed. Filter by
plant family, swipe left for "not sure", and the end-of-deck summary groups what
you got wrong by family.

**Play without downloading anything:** https://s4me4su.github.io/weed-flashcards/

## Install on Android

1. Tap the APK download.
2. Android warns about "unknown sources" / "not verified by Play Protect" -
   normal for any app installed outside the Play Store. Choose **Allow** /
   **Install anyway**.
3. Open **Weed ID Trainer** from the app drawer.

If the arm64 APK refuses to install, use the plain one - it runs everywhere.
A newer APK installs over the old one and keeps the saved deck.

## Install on Windows

1. Right-click the zip, choose **Extract All** (do not run it from inside the zip).
2. Open the folder and run **weeds_flashcards.exe**. Right-click -> Send to ->
   Desktop makes a shortcut.

No installer, no administrator rights. Progress is kept in
`weeds_deck_v1.json` next to the exe, so keep the folder together - it can ride
on a USB stick.

## iPhone

Use the web link above, then **Share -> Add to Home Screen**. It gets an app
icon, opens full screen and keeps working offline once the cards are cached.

## Progress and privacy

Position, removals, review marks and the family filter save automatically, on
the device only - in the browser, in the app folder, or in the app's own
storage. Nothing is uploaded and nothing needs an account. Clearing browser data
resets web progress.
